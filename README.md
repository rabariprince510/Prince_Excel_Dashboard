# HR Employee Attrition Analysis & Excel Dashboard

## 📊 Project Overview

The **HR Employee Attrition Analysis Dashboard** is a data analytics project developed using Microsoft Excel to explore employee turnover, workforce demographics, job satisfaction, and departmental performance.

The project uses an HR Employee Attrition dataset containing **1,470 employee records and 35 columns**. It transforms raw employee data into meaningful summaries and key performance indicators (KPIs) to help HR professionals understand attrition patterns and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze employee attrition and calculate the overall attrition rate.
- Compare employee turnover across departments and job roles.
- Examine workforce characteristics and employee demographics.
- Summarize average monthly income and job satisfaction.
- Apply Excel formulas and data analysis techniques to extract insights.
- Present important HR metrics in an executive-style dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Excel** — Data analysis and dashboard development
- **Excel Formulas** — KPI calculations and conditional logic
- **Pivot Tables & Aggregations** — Summarizing employee data
- **Data Visualization** — Presenting HR metrics and trends
- **Conditional Formatting** — Highlighting important values
- **CSV Dataset** — Source employee data

## 📈 Key Performance Indicators (KPIs)

The dashboard includes the following core metrics:

- **Total Workforce:** Number of employees represented in the dataset.
- **Total Attrition:** Number of employees recorded as having left the organization.
- **Overall Attrition Rate:** Percentage of employees who left the organization.
- **Average Monthly Income:** Average monthly income across employees.

## 🔍 Analysis Performed

### 1. Department-Wise Analysis
- Compared workforce size across departments.
- Calculated attrition counts and rates.
- Examined average monthly income and job satisfaction by department.

### 2. Job Role Analysis
- Compared employee turnover across different job roles.
- Identified roles with relatively high and low attrition rates.
- Summarized the number of employees and attrition rate for each role.

### 3. Employee Data Analysis
The dataset contains information about:
- Age and gender
- Department and job role
- Monthly income and salary hikes
- Job and environment satisfaction
- Business travel and overtime
- Years of experience and tenure
- Work-life balance and relationship satisfaction

### 4. Dashboard Development
Organized important HR metrics into an executive-style dashboard to make workforce trends easier to understand and communicate.

## 🚀 How to Use the Project

1. Download or clone this repository.
2. Open `Rabari_Prince_ExcelDashboard.xlsx` in Microsoft Excel.
3. Review the `Instructions` and `Tasks` worksheets.
4. Explore the `Dataset` worksheet to understand the source records.
5. Review the `Summary & Pivot` worksheet for the analytical summaries.
6. Open the `Dashboard` worksheet to examine the key HR metrics.

For the best experience, use a desktop version of Microsoft Excel that supports the workbook's formulas and dashboard features.
